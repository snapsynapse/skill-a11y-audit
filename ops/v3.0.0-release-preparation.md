## Delivery gates

1. Commit and push the reviewed migration paths. Require all checks on the
   exact PR head, including the Node 22.12.0 floor, browser and external
   consumer lanes, actual Action invocation, GuideCheck, and workflow audits.
2. Merge the tested candidate and verify validation and Pages checks on the
   resulting main commit before tagging it.
3. Create a signed annotated v3.0.0 tag. Package tar.gz and zip archives from
   that exact commit, verify a clean archive consumer, and publish a GitHub
   release with SHA-256 digests. This private npm package is distributed as a
   skill bundle through GitHub; npm registry publication does not apply.
4. Verify the remote tag, downloaded release assets, and live documentation
   against the release commit and clean site build.
5. Recheck Dependabot alert 2 after main's dependency graph updates. Record
   automatic closure or dated stale-alert evidence in the release notes.
6. Record delivered evidence in the existing LocalBrain project note and
   remove the processed temporary handoff.
