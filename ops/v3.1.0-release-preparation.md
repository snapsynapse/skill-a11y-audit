2. Publish a scoped branch and PR; require all existing validation, browser, consumer, guide and workflow checks on the exact candidate commit.
3. Merge only the passing candidate and verify main validation and Pages deployment on the resulting commit.

No new registry, recurring automation, shared workflow repository or consumer migration is part of this delivery proposal.
